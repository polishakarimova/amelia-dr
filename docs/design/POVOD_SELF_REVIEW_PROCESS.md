# Povod Self Review Process

Перед завершением любой дизайн-задачи пройти самопроверку.

## Чек-лист

- Прочитан ли brand guide?
- Прочитаны ли UI rules?
- Проверена ли папка `docs/design/assets/logo-reference`?
- Используется ли approved SVG-логотип `gift_arch_symbol_exact_v2.svg`?
- Проверен ли do-not-repeat?
- Соответствует ли экран метафоре “хаос -> одна ссылка -> праздник”?
- Не выглядит ли экран как SaaS?
- Не выглядит ли экран как CRM?
- Нет ли старого логотипа?
- Нет ли перерисованного или замененного логотипа?
- Есть ли мягкая палитра?
- Есть ли визуальный главный герой?
- Удобно ли на мобиле?
- Нет ли горизонтального скролла?
- Не слишком ли много пустоты?
- Не слишком ли все белое?
- Нет ли дефолтных input / file upload?
- Сделана ли оценка по rubric?

## Формат self-review

```md
### Self-review

Бренд-стиль: X/20
Brand guide: X/15
Понятность за 3 секунды: X/15
Hero / preview: X/15
Компоненты: X/10
Mobile-first: X/10
Не SaaS / не CRM: X/10
Детали: X/5

Итог: X/100

Что доработано после оценки:
- ...
```

## Правило

Если итог меньше 90/100, нельзя завершать дизайн-задачу без доработок.

Если задача только про дизайн-документы, достаточно подтвердить, что UI не менялся.
