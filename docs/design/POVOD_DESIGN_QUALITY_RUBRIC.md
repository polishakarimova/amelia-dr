# Povod Design Quality Rubric

Оцени каждый дизайн-экран по шкале 0-100.

Экран считается готовым только если набирает минимум 90/100. Если меньше — нужно дорабатывать.

## 1. Попадание в бренд-стиль — 20 баллов

Проверить:

- warm celebration card system;
- soft festive invitation UI;
- мягкая праздничность;
- теплый digital-продукт;
- не SaaS, не CRM, не админка.

## 2. Визуальная близость к brand guide — 15 баллов

Проверить:

- палитра;
- логотип;
- Onest;
- мягкие скругления;
- теплые рамки;
- легкие тени;
- дружелюбные иконки.

## 3. Понятность продукта за 3 секунды — 15 баллов

Проверить:

- понятно ли, что это карточка праздника в одной ссылке;
- понятна ли польза для гостя;
- понятна ли польза для организатора;
- виден ли CTA.

## 4. Качество hero / preview — 15 баллов

Проверить:

- есть ли визуальный главный герой;
- видно ли “хаос -> одна ссылка -> праздник”;
- preview не выглядит техническим;
- hero не перегружен.

## 5. Качество компонентов — 10 баллов

Проверить:

- кнопки;
- карточки;
- чипсы;
- формы;
- gift cards;
- статусы;
- upload;
- stepper.

## 6. Mobile-first — 10 баллов

Проверить:

- 390px без горизонтального скролла;
- CTA виден;
- текст не обрезается;
- карточки читаемы;
- header не перекрывает контент.

## 7. Отсутствие шаблонного SaaS — 10 баллов

Проверить:

- нет CRM-ощущения;
- нет пустых белых карточек без характера;
- нет скучной админки;
- нет технических file inputs и дефолтных форм.

## 8. Аккуратность деталей — 5 баллов

Проверить:

- ровные отступы;
- нет случайных градиентов;
- нет лишнего визуального шума;
- состояния hover/focus/disabled продуманы.

## Порог

- 90-100: готово.
- 80-89: близко, но нужно доработать.
- 70-79: черновик.
- ниже 70: не соответствует бренду.
