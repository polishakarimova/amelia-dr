# Povod Brand Guide

## Суть продукта

«Повод» — сервис для создания красивой карточки праздника в одной ссылке.

Внутри карточки:

- дата;
- время;
- место;
- карта;
- приглашение;
- пожелания;
- список подарков;
- ссылки;
- картинки;
- цены;
- бронь подарков гостями, чтобы не было дублей.

## Главная метафора

> хаос в переписках -> одна ссылка -> красивый собранный праздник.

«Повод» превращает разрозненные сообщения, вопросы гостей и дубли подарков в одну теплую, понятную и красивую карточку.

## Настроение

- теплое;
- мягкое;
- праздничное;
- дружелюбное;
- чистое;
- современное;
- слегка иллюстративное;
- заботливое;
- собранное.

## Аудитория

Стартовая аудитория: мамы детей 1-10 лет, которые организуют день рождения ребенка.

Бренд должен быть универсальным и подходить также для:

- взрослого дня рождения;
- baby shower;
- свадьбы;
- новоселья;
- девичника;
- семейного праздника.

## Бренд-слова

## Типографика

- Основной шрифт: Onest.
- Заголовки мягкие, крупные, но не грубые.
- Текст не должен быть слишком серым.
- Интерфейс должен быть читаемым и воздушным.
- Не делать огромные тяжелые черные заголовки.

## Approved Logo

Финальный логотип находится в:

- `docs/design/assets/logo-reference/gift_arch_symbol_exact_v2.svg`

Это SVG-логотип с коралловой аркой / буквой «П», внутренней карточкой, подарком / бронью и золотой искрой.

Правила:

- логотип нельзя перерисовывать;
- нельзя менять форму логотипа;
- нельзя упрощать до случайной иконки;
- нельзя заменять на lucide/shadcn icon;
- нельзя использовать старый логотип из бренд-коллажа как основной;
- для интерфейса можно использовать копию `public/brand/povod-logo.svg`.

## Иконки

Иконки должны быть дружелюбными, мягкими и слегка иллюстративными.

Подходящие мотивы:

- подарок;
- карточка;
- ссылка;
- карта;
- гости;
- чек / бронь подарка;
- искра;
- сообщение / чат.

## Формы

Формы должны ощущаться как конструктор праздничной карточки, а не как техническая админка.

- labels обязательны;
- placeholder только как пример;
- upload photo не должен быть стандартным file input;
- stepper должен быть дружелюбным;
- поля теплые, с мягкими рамками и подсказками.

## Карточки

Карточка праздника — главный герой интерфейса.

Карточки должны быть:

- теплыми;
- мягкими;
- с большими скруглениями;
- с тонкими теплыми рамками;
- с легкими тенями;
- не пустыми белыми прямоугольниками.

## Иллюстративность

Допустима легкая иллюстративность:

- мягкие blur-пятна;
- золотая искра;
- иконки подарков;
- визуальная история “чат -> ссылка -> карточка”.

Не переносить бренд-коллаж буквально на каждый экран.

## Как должен ощущаться сайт

Сайт должен ощущаться как теплый digital-праздник: красиво, понятно, спокойно, с заботой о гостях и организаторе.
