# Povod Card Template System

Документ фиксирует будущую архитектуру первого шага создания карточки «Повод».

## Цель

Первый экран создания карточки должен быть проще и красивее:

1. Сначала пользователь выбирает цвет.
2. Затем выбирает формат: с фотографией или без фотографии.
3. Потом выбирает конкретный шаблон внутри выбранного цвета и формата.

Это заменит текущую логику выбора типа повода как основного визуального шага.

## Цвета

Основные варианты:

- `pink` — розовый;
- `blue` — голубой;
- `beige` — бежевый.

На первом экране они должны отображаться как три круглые кнопки в одну линию.

Состояние выбранного цвета:

- заметная обводка;
- лёгкое увеличение или тень;
- галочка или маленькая искра допустима, если не перегружает UI.

## Фото-режим

После выбора цвета показывается выбор:

- `with-photo` — шаблоны с круглой фотографией;
- `without-photo` — шаблоны без фотографии.

После выбора режима показываются только релевантные шаблоны.

## Ассеты

Все ассеты лежат в:

`public/card-templates`

Структура:

- `public/card-templates/swatches`
- `public/card-templates/pink/with-photo`
- `public/card-templates/pink/without-photo`
- `public/card-templates/blue/with-photo`
- `public/card-templates/blue/without-photo`
- `public/card-templates/beige/with-photo`
- `public/card-templates/beige/without-photo`
- `public/card-templates/shared`

## Шаблоны с фото

В шаблонах `with-photo` должен быть круг под фотографию.

Код должен хранить для каждого шаблона координаты круга:

```js
photoSlot: {
  x: 50,
  y: 22,
  size: 34
}
```

Значения лучше хранить в процентах от ширины/высоты шаблона:

- `x` — центр круга по горизонтали;
- `y` — центр круга по вертикали;
- `size` — диаметр круга в процентах от ширины шаблона.

Так фотография пользователя сможет точно лечь в круг независимо от размера экрана.

## Поведение выбора

Будущая структура состояния события:

```js
{
  theme: "pink",
  templateMode: "with-photo",
  templateId: "pink-photo-01",
  coverImage: "/uploads/..."
}
```

Если выбран `without-photo`, поле `coverImage` можно не требовать.

Если выбран `with-photo`, загрузка фото должна вести к crop-интерфейсу под круг, а не под прямоугольную обложку.

## Градиент

Картинки шаблонов могут иметь градиент, уходящий в белый снизу.

Нижние блоки карточки:

- дата;
- время;
- место;
- пожелания;
- подарки;

должны визуально продолжать шаблон, а не выглядеть отдельной чужой карточкой.

## Что нельзя делать

- Не смешивать розовые, голубые и бежевые шаблоны в одной папке.
- Не хранить кружочки выбора цвета рядом с шаблонами карточек.
- Не использовать прямоугольный crop для шаблонов с круглым фото.
- Не делать выбор шаблона похожим на админку.
- Не ломать текущий редактор до загрузки и утверждения ассетов.
