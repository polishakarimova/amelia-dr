# Invitation Icon Assets

Папка для цветных иконок и декоративных элементов, которые будут использоваться внутри создания и публичной карточки приглашения.

## Структура

- `pink/` — иконки для розовых шаблонов.
- `blue/` — иконки для голубых шаблонов.
- `beige/` — иконки для бежевых шаблонов.

## Как лучше называть файлы

Лучше класть иконки сразу в папку нужного цвета и называть одинаково во всех цветах:

- `calendar.svg` — дата.
- `clock.svg` — время.
- `location.svg` — место / адрес.
- `gift.svg` — подарки.
- `heart.svg` — сердечко / мягкий декоративный акцент.
- `bow.svg` — бантик / праздничный декоративный акцент.
- `sparkle.svg` — искра.
- `star.svg` — звезда.
- `guest.svg` — гости.
- `link.svg` — ссылка.
- `wishlist.svg` — список подарков.

Например:

```text
pink/calendar.svg
blue/calendar.svg
beige/calendar.svg
```

Так код сможет автоматически брать нужную иконку по выбранному цвету карточки.

## Формат

Лучший вариант — `svg` с прозрачным фоном.

Если иконка только в растре, можно использовать `png` с прозрачным фоном. Желательно размер 256x256 или 512x512, чтобы она хорошо смотрелась на retina-экранах.

## Важно

Не нужно делать отдельную папку под каждую иконку. Удобнее хранить по цветам, а внутри каждой цветовой папки использовать одинаковые смысловые названия.
