# Card Templates Assets

Папка для ассетов нового первого шага создания карточки в проекте «Повод».

Логика выбора:

1. Пользователь выбирает цвет: pink, blue или beige.
2. После выбора цвета пользователь выбирает режим: with-photo или without-photo.
3. После этого показываются шаблоны выбранного цвета и режима.

## Структура

- `swatches/` — круглые картинки-кружочки для выбора цвета.
- `pink/with-photo/` — розовые шаблоны с круглым фото.
- `pink/without-photo/` — розовые шаблоны без фото.
- `blue/with-photo/` — голубые шаблоны с круглым фото.
- `blue/without-photo/` — голубые шаблоны без фото.
- `beige/with-photo/` — бежевые шаблоны с круглым фото.
- `beige/without-photo/` — бежевые шаблоны без фото.
- `shared/` — общие декоративные элементы, если понадобятся.

## Рекомендованные имена

Кружочки цвета:

- `pink-swatch.png`
- `blue-swatch.png`

Шаблоны:

## Важно

Для шаблонов с фото оставляй круг под фото в одном и том же месте внутри картинки. Потом код будет накладывать загруженную пользователем фотографию именно в этот круг.

Фон шаблона может уходить градиентом в белый снизу: ниже картинки будут блоки с датой, временем, местом, пожеланиями и подарками.
